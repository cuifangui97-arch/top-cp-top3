GitHub Pages 上传说明

1. 在 GitHub 新建一个公开仓库，例如 top-cp-top3。
2. 解压本文件夹，将 index.html、og-kunchan.jpg、assets/ 直接上传到仓库根目录。
3. 打开仓库 Settings > Pages，选择 Deploy from a branch；分支选 main，目录选 /(root)，保存。
4. 发布后地址通常为 https://你的用户名.github.io/top-cp-top3/ 。

注意：index.html 的社交平台预览图目前仍指向原站域名。确定新地址后，可把 og:image 和 twitter:image 的 URL 改为新 GitHub Pages 地址加 og-kunchan.jpg，以免预览图依赖原站。
